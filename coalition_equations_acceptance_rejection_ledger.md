## Part 2: Standard Equations Rejected & Technical Reasons for Rejection

| Standard Physics Framework / Equation | Standard Formulation | Reason for Rejection in Coalition Model |
| :--- | :--- | :--- |
| **Einstein Field Equations** | $G_{\mu\nu} + \Lambda g_{\mu\nu} = \frac{8\pi G}{c^4} T_{\mu\nu}$ | **Reason:** Rejects pseudo-Riemannian spacetime curvature and abstract manifolds. Space is treated as a flat reference space containing a physical, variable vacuum matrix (`EQ-080`, `EQ-120`). |
| **Geodesic Deviation Equation** | $\frac{d^2 x^\mu}{d\lambda^2} + \Gamma^\mu_{\alpha\beta} \frac{dx^\alpha}{d\lambda} \frac{dx^\beta}{d\lambda} = 0$ | **Reason:** Rejects Christoffel symbol metric curvature; paths are governed by real physical medium interactions, optical refraction (`EQ-098`), and mechanical field forces rather than free-falling geometry. |
| **Kerr / Schwarzschild Metric Line Element** | $ds^2 = -\left(1 - \frac{2GM}{rc^2}\right)dt^2 + \dots$ | **Reason:** Rejects infinite density point-singularities and event horizon coordinate singularities. Replaced by finite-density thermal-coupled core arrest boundaries ($r_h$) governed by `EQ-033` and `EQ-101`. |
| **Cosmological Expansion Metric** | $1 + z = \frac{a(t_{\text{now}})}{a(t_{\text{emit}})}$ | **Reason:** Rejects the metric expansion of space. Redshift is accounted for natively via non-ballistic photon momentum depletion ($\Delta p_\gamma$) across path resistance (`EQ-027`, `EQ-028`). |
| **General Relativistic Lensing** | $\theta = \frac{4GM}{c^2 b}$ | **Reason:** Rejects light bending via warped empty space. Light deflection is modeled as pure optical refraction through a variable vacuum index gradient ($n(r)$) per `EQ-098` and `EQ-100`. |
| **Copenhagen Wave Function Collapse** | $\hat{A}|\psi\rangle = a_i|\psi_i\rangle$ | **Reason:** Rejects observer-dependent probabilistic collapse. State determinations are treated as deterministic physical interactions with the local medium environment (`EQ-016`, `EQ-120`). |
